# Canon

This folder is the bible. It wins when a note outside it disagrees. `concept.md` is the early premise and loses to every other file here. `pitch.md` is the public pitch.

Each folder has a `README.md` that says which file answers which question. A README is an index. The fact lives in the file it names.

Before a chapter, open:

* `characters/tsunari.md` or `characters/vram.md`, for the point of view on the page.
* `plot/book1/README.md`, then the part file that holds the chapter.
* `places/locations_and_sensory.md`, when a listed place is on the page.
* `romance/romance_engine.md`, when they touch.
* `world/air.md`, when they are outside.
* `style/voice.md` and `style/glossary.md`, when the job is the wording.

`world/cradle.md` is the Book 3 geography. Do not load it for a Book 1 scene.

The manuscript, the prompts, the media, the reviews, the Kindle copy, and the reader stay at the repo root.
